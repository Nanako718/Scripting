# 更新日志

## v1.2.5 (2026-09-10)

- 新增：阶梯进度条样式可选（三色渐变 / 纯色原始）
- 新增：阶梯百分比计算方式可选（全量 / 阶梯）
- 新增：三色进度条支持超出第三阶梯后动态扩展显示区域
- 新增：进度条下方显示年度用电量标注
- 新增：组件宽度自适应不同设备（使用 Widget.displaySize）
- 优化：阶梯进度条布局调整（左侧当前阶梯+百分比，右侧剩余/超出度数）
- 优化：超出第三阶梯时百分比允许超过100%，文字用弱化红色凸显

## v1.2.4 (2026-09-09)

- 新增：国网 Logo 尺寸自定义（默认 48，可选 40–56，步长 2）
- 新增：近日用电小数位设置（整数 / 1 位 / 2 位，默认 2 位）
- 优化：余额显示逻辑简化——开关开启后一律显示「账户余额」，不再回退到上期电费
- 更新：README 新增 BoxJs 配置、重写订阅、使用风险说明

## v1.2.3 (2026-09-08)

- 修复：开启「左栏显示余额」后部分用户仍无法显示账户余额的问题，不再依赖 isPostPaid 判断，改为根据余额数据是否有效决定显示
- 开启余额显示但未获取到有效数据时，显示「数据获取失败」提示，不再回退到上期电费
- 柱状图天数新增 14 天选项
- 柱状图显示度数功能优化：包含 7 天、间距调整、度数加粗

## v1.2.2 (2026-09-08)

- 新增「柱状图显示度数（≤7天）」设置项，启用后在柱顶标注用电度数（四舍五入取整，加粗显示）
- 设置项「后付费显示余额」更名为「左栏显示余额」
- 修正「显示户名」描述：关闭时左栏顶部显示国家电网 logo 图标
- README 补充「左栏显示余额」「柱状图显示度数」设置说明
- 修正柱状图天数范围描述（5–12 天）

## v1.2.1 (2026-09-07)

- 日用电柱状图参照原 Scriptable 脚本逻辑：柱宽 5pt、间距 6pt 固定不变，图表宽度随选择天数自然增长
- 新增「左栏显示余额」设置项（后付费账户专用），开启后左栏显示账户余额
- 左栏金额显示优先级：待缴电费 > 账户余额 > 上期电费
- 左侧国网 logo 尺寸调整为 50×50
- 左侧更新时间改为绝对时间显示
- 设置保存后不再自动刷新小组件，避免频繁访问触发风控
- README 补充设置项文档

## v1.2.0 (2026-09-07)

- 初始版本，移植自 Scriptable 脚本「网上国网」（@脑瓜 v2.3.3）
- 中型小组件右侧三栏自由定制：每栏可选「组合一/二/三」或「阶梯电量」
- 9 种指标可自由搭配：上期电费、上月电量、年度电费、年度电量、本月电量、近日用电、电费余额、日用电图表、不显示
- 阶梯用电横条 + 当前档位进度
- 多账户支持，桌面小组件可按参数选户
- 阶梯口径可自设（默认山东口径）
