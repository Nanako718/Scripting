## 功能

- **右侧三栏自由定制**：第一/二/三栏均可独立选择「组合一/二/三」或「阶梯电量」，每个组合的左/右栏内容可从 9 种指标中自由搭配
- 阶梯用电横条 + 当前档位第 N 阶梯·xx% + 滑块定位
- 近 N 日用电柱状图
- **多账户**：一个账户下有多个「户」时，可选账户并区分
- **多户名**：可给每户起自定义名字，支持桌面多小组件分别显示不同户
- **阶梯可自设**：默认山东口径（按月 210/400 度、按年累计 2520/4800 度），可在设置里覆盖
- **口径可切换**：按年累计 / 按月计算
- 桌面小组件按「参数」选户（户名或 1/2/3）

### 配置步骤

1. 在代理工具中导入并启用对应的重写订阅。
2. 在 BoxJs 中导入上述订阅链接，填写国网登录账号和密码。
3. 开启代理 + 开启重写 + 开启 MITM。
4. 在 Scripting 里运行设置页，点「获取账户列表」拉取数据。

> 若 Scripting 小组件取不到数，多半是重写未生效或超时（已设为 60s，与重写侧一致）。请先确认代理、重写、MITM 均已开启。

## 安装（Scripting app）

1. 将本项目复制/导入到 Scripting app 的脚本目录。
2. 打开 **index.tsx**（设置页），点右上角运行，进入设置：
   - 先点「**获取账户列表**」，出现你的账户（一个账户下可能有多个户）。
   - 用「**当前账户**」选择要默认显示的账户。
3. 如需区分多户，在「**多户配置**」里给每户起名。
4. 在桌面**添加中号小组件**（systemMedium），绑定本脚本。
5. 每个小组件在配置面板的「**参数（Parameter）**」里填对应户名或 `1`/`2`/`3` 即可固定显示某一户；留空则用设置里的「当前账户」。

> 记得：改动设置后点右上角「**保存**」，小组件下次刷新才会读到新配置。

| 项 | 说明 |
|---|---|
| 获取账户列表 | 从国网接口拉取当前登录账号下的账户 / 户列表 |
| 当前账户 | 默认显示的账户下标（0 起） |
| 户 1/2/3 名称 | 自定义户名，会在小组件左上方显示；留空则显示实际户名 |
| 显示户名 | 关闭时左栏顶部显示国家电网 logo 图标 |
| 国网 Logo 尺寸 | 未显示户名时，左栏国网 logo 图标的边长（默认 48，可选 40–56） |
| 左栏显示余额 | **后付费账户专用**。开启后左栏显示「账户余额」，关闭则显示「上期电费」。欠费时始终优先显示「待缴电费」并红色高亮，与此开关无关 |
| 柱状图显示度数 | 开启后在柱顶标注用电度数（四舍五入取整），仅适用于 7 天及以下 |
| 柱状图天数 | 近 N 日用电柱状图的天数（5–14） |
| 近日用电小数位 | 近日用电度数的保留小数位数（整数 / 1 位 / 2 位） |
| 第一栏 / 第二栏 / 第三栏 | 每栏可选「组合一/二/三」或「阶梯电量」；选为组合时下方出现左/右栏内容 Picker |
| 组合左/右栏内容 | 可选指标见下表「可选项指标」 |
| 阶梯口径 | 按年累计 / 按月计算 |
| 柱状图颜色 / 主题色 | 自定义配色 |
| 第二/三档阈值 | 单位度；留空按山东口径自动（按月 210/400、按年 2520/4800） |
| 刷新间隔 | 60 分钟–24 小时 |
| 清除缓存 | 清空本地缓存数据 |
| 预览中号小组件 | 「真实数据」走接口，「演示数据」不联网、用于校对布局 |
| 恢复默认设置 | 还原全部设置 |

## 右侧三栏配置说明

中号组件右侧分为三栏（第一栏、第二栏、第三栏），每栏可独立配置：

- **组合一 / 组合二 / 组合三**：显示左右两个指标，可自由搭配
- **阶梯电量**：显示阶梯用电横条 + 当前档位进度

### 可选指标

| 指标 | 说明 |
|---|---|
| 上期电费 | 上个计费周期的电费金额（元） |
| 上月电量 | 上月用电量（度） |
| 年度电费 | 本年度累计电费（元） |
| 年度电量 | 本年度累计用电量（度） |
| 本月电量 | 本月已用电量（度） |
| 近日用电 | 近 N 日平均日用电量（度），大号显示 |
| 电费余额 | 当前账户余额（元），有待缴时以红色高亮 |
| 日用电图表 | 近 N 日柱状图 |
| 不显示 | 该位置留空 |

> 默认配置：第一栏＝年度电费 · 上月电量，第二栏＝阶梯电量，第三栏＝日用电图表 · 近日用电。

## 桌面多小组件区分（参数选户）

每个小组件实例可独立设置「参数」，按以下规则决定显示哪一户：

1. 参数 = 某个自定义户名（忽略大小写）→ 显示那一户，并套用该户名；
2. 参数 = 数字 `1` / `2` / `3` → 显示对应账户；
3. 参数为空 → 用设置里的「当前账户」。

这样，你可以在桌面放多个小组件，分别绑定不同户，一眼区分。

## 阶梯口径说明（山东）

默认按山东居民阶梯：

- 按月：一档 ≤210 度、二档 211–400 度、三档 >400 度；
- 按年累计：一档 ≤2520 度、二档 2521–4800 度、三档 >4800 度。

各地档位与政策会调整，请在「阶梯」里按自己实际电表档位填写以覆盖默认值。
（部分地区已执行一档 260 度/月等新政，可在设置里手动改为对应值。）
